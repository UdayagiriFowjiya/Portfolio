# 💼 Personal Portfolio – HTML & CSS
A responsive personal portfolio website built using pure HTML and CSS, showcasing my profile & projects. This static website is designed to provide a clear, elegant overview of my skills and experience.

## 🧩 Sections Included
Home – Brief introduction with name and title

About – Short bio & Academic qualifications

Skills – Technical skills listed visually

Experience - Listed internships with links and certificates

Projects – Highlighted works with descriptions and links

Contact – Email, social media links

## 🛠️ Technologies Used

HTML5

CSS3

Font Awesome (for icons)

## 📱 Features
Responsive design for desktop

Smooth scrolling navigation

Clean, modern layout
